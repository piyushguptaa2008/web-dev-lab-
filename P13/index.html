P13 / LAYOUT SYSTEMS

Flexbox vs CSS Grid

Flexbox

A one-dimensional layout system used for arranging elements in a row or column.

  • Navigation bar
  • Skill tags
  • Project buttons
  • Footer alignment

CSS Grid

A two-dimensional layout system used for arranging elements in rows and columns.

  • Practical cards
  • Project galleries
  • Comparison section
  • Responsive layouts
